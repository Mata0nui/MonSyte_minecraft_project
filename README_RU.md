# ZalupaServer React

## Запуск в VS Code

```powershell
npm.cmd install
npm.cmd run dev
```

Открой ссылку Vite, обычно `http://localhost:5173/`.

## Разделы

- Главная
- Режимы
- Привилегии
- Пространство
- Скины
- Другие фишки
- Другие сервера

Верхний поиск меняет результаты на активной вкладке. Карточки и окна подробностей адаптированы под текущую палитру сайта: белый фон, тёмно-синий и оранжевый акценты.

**Важно:** цены, описания товаров, онлайн и режимы в этой сборке — демонстрационные данные. Перед публикацией замени их на реальные. Оплата пока не подключена.
