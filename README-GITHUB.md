# ZalupaServer — изображения через GitHub

Все игровые изображения вынесены из проекта и теперь загружаются с публичного GitHub-репозитория:

`https://github.com/Mata0nui/IP_Photo_mineCraft_server`

В проекте используются абсолютные внешние URL, поэтому фотографии будут загружаться независимо от того, где размещён сам сайт или в какую папку пользователь его скачал.

Основной источник — jsDelivr CDN, резервный — `raw.githubusercontent.com`.

Используемые файлы:

- `charcoal.png`
- `flint.png`
- `iron_nugget.png`
- `gold_ingot.png`
- `golden_apple.png`
- `totem_of_undying.png`

Важно: для работы нужен доступ пользователя к интернету. Саму папку `public/*.png` из этого проекта можно больше не хранить — изображения находятся в GitHub.
